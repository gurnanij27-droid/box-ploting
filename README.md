# CSS Box Model
About the Project

This project demonstrates the CSS Box Model using HTML and CSS. It explains the four main parts of the box model: Content, Padding, Border, and Margin.

# Technologies Used
HTML5
CSS3
# Features
Displays the CSS Box Model
Different background colors for each section
Demonstrates margin and padding
Shows border and content areas
Uses CSS Flexbox for alignment
Uses positioning and text styling
Box Model Components
Content: The actual text or content inside the box.
Padding: The space between the content and the border.
Border: The boundary around the content and padding.
Margin: The space outside the border.
# How to Run
Save the code as box-1.html.
Open the file in any web browser.
View the different parts of the CSS Box Model.
